The task is five-class classification of the pig inside each provided box, one output per original row_id. No boxes are predicted. Class names follow the source pig_posture_classes.txt, indexed 0–4.

train.csv is a two-row catalog pointing to the actual T1/train.csv and T2/train.csv fitting tables. Each fitting table retains the native row_id,image_id,width,height,bbox,class_id fields and adds crop_index and image_path. bbox is absolute [xmin,ymin,width,height] in the original frame dimensions, not normalized. image_path is relative to the head directory and leads to the unchanged original JPEG. Each row's crop_index addresses that head's train_crops.npy, an N×64×64×3 uint8 RGB array. Crops use floor(xmin,ymin), ceil(xmax,ymax), clipped to the image; the native bbox stays unchanged. Crops are bilinearly resized with Pillow. Full JPEG frames remain available for other processing.

validation.csv contains public labels for model selection only, never fitting. test.csv has the same instance and box information without class_id. Their image_path values are relative to data/. Class-free inference/{validation,test}/instances.csv and crops.npy are provided so either fitted head can infer in a view that contains no evaluation labels. These crop indices address the corresponding inference split, not a fitting array. A head must use its own allowed fitting data and fit all learned preprocessing within that setting. No T2-only fitting information may be used by T1. Separate heads and independently selected model choices are allowed.

Fitting uses original labeled frames dated through 2025-02-03. Validation uses 2025-02-07 and 2025-02-09; test uses 2025-02-15 and 2025-02-20. All instances of a frame and all camera views for each pen/date stay together. Adjacent frames from a date never span splits. T2 retains 44 extra frames (396 instances) from target-camera contexts dated 2025-01-20, 2025-02-01 and 2025-02-03. Its 16 extra frames from 2025-02-17 are omitted to preserve chronology; they are neither fitting nor evaluation inputs. The source official unlabeled September test is unused.

The local validation/test cameras are pen1_tur_cam2 and pen2_tur_cam1, already present in fitting. Original target-camera contexts are preserved in T2, but the source's original unseen-camera and unseen-animal test shift cannot be reproduced with labeled data. Different filenames/dates do not establish different individual pigs. There are no animal or verified production-batch IDs: pen/date groups are observable proxies. This build claims frame/date separation and audited camera overlap, not verified biological animal disjointness. Public labels were inspected during construction, so this is exploratory reconstructed evaluation.

Each prediction member is exactly row_id,class_id with all test IDs once. sample_submission.csv is a single-head all-zero schema example; sample_submission.zip contains both all-zero heads and is only a format example. Produce _submission.zip containing exactly T1_submission.csv and T2_submission.csv at its root. bundle_predictions.py packages already-produced native CSV files without fitting or scoring. The paired ZIP is solely a local runner artifact convention. Do not include fitting data, labels, model files or extra files inside it.

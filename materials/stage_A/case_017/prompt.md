Predict two binary targets for each participant using functional MRI connectomes and socio-demographic, questionnaire and parenting metadata: ADHD_Outcome (1=ADHD, 0=Other/None), and Sex_F (1=Female, 0=Male).

Data comes from the updated TRAIN_NEW release. Public files data/train.csv and data/validation.csv contain participant_id, 27 metadata features and both targets. data/test.csv contains participant_id and the identical metadata fields, without targets. Participant IDs are strings: preserve them exactly. data/connectomes_train.npz, data/connectomes_validation.npz and data/connectomes_test.npz contain all 19,900 original connectome columns as a float32 array named features and string array participant_ids, in matching CSV row order. data/feature_schema.json lists original names and which metadata fields are categorical. No connectome columns were selected. Metadata retain numeric float64 values; missing cells are empty. Fit imputers, scalers, feature selectors and models on training data; use public validation for model and threshold selection. Only one participant occurs per row and no participant is shared between partitions. Sites occur in multiple partitions: this evaluates new participants in represented sites, not generalization to new sites. Family identifiers are not supplied, so related-family separation cannot be guaranteed.

Write submission.csv with exactly participant_id,ADHD_Outcome,Sex_F, one row for every test ID in test.csv order, with no missing, extra or duplicate IDs. Both predictions must be literal hard binary 0 or 1. Probabilities, blanks, NaN and 0.0/1.0 strings are not accepted. Choose any model or threshold using permitted public data. Do not use hidden reference labels, external datasets or downloads. Do not access other task files or original source releases outside the staged data.

Evaluation uses one fixed population, all supplied test rows. A reference row has weight 2 exactly when both reference targets equal 1 (female ADHD), otherwise 1. This same reference-derived vector weights both target scores; it never depends on predicted labels. Weighted F1 is calculated separately for each target, and the two target scores are averaged equally. For a class-specific F1, count TP, FP and FN with these row weights and calculate 2TP/(2TP+FP+FN); return zero when that denominator is zero. Higher final scores are better; equal scores remain ties.

Execution budget: 30 minutes, 2 CPUs, 4 GiB RAM. Python numpy, scipy, pandas and scikit-learn are available. No extra dependency is needed to read the staged data. This is a local research reconstruction; retain the source competition's data-use restrictions and do not redistribute participant data.

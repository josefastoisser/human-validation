Spanish 5W1H extraction research dataset. Each row is a text fragment, not necessarily a whole article. Train/validation labels are available; test labels are private. IDs are opaque alignment keys. All conditions use identical rows and raw text. Example: python data/baseline.py --train data/train.csv --inputs data/test.csv --output submission.csv . The baseline is optional. This local package is for the supplied research task; no external downloads are required.

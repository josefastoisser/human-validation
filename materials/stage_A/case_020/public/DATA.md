498 frozen images yield1346 ROIs: train678,validation267,test401. All regions from each image/acquisition remain together. The sample is a bounded available-image pilot rather than a representative sample of the full competition. Retain the complete79-class target vocabulary; some targets may be absent from fitting data. train.csv and validation.csv contain annotation_id,image_id,crop_path,concept_name. test.csv contains the same first three columns and no labels. IDs are join keys, not predictive features. Use crop pixels for inference. All crops are RGB PNG, with left/top floored and right/bottom ceiled then clipped to source bounds. Original annotations and source photographs remain unmodified.

The two JSON taxonomy files provide fixed seven-rank lineages:79 original labels and192 total named targets/ancestors. Original entries are unchanged and new entries truncate the existing lineage after the ancestor rank; null denotes no supplied lower rank. No external taxonomy is required. sample_submission.csv contains blank predictions as a valid12-loss format example, without test labels. Every condition receives the same files.

Identify marine animal taxa in the supplied image regions. train.csv and validation.csv contain original concept_name labels; test.csv contains unlabeled regions. Each crop_path is relative to data/. Images are lossless crops of supplied photographs using the original bounding boxes. Use only these local assets; no new images, taxonomy queries or pretrained weights. taxonomy.json contains the79 original target lineages; taxonomy-extended.json additionally provides113 named ancestor lineages. All79 target classes remain in the task vocabulary, including classes absent from fitting data. This local pilot has678 training,267 public-validation and401 test regions. Photographic acquisitions are disjoint across partitions.

Write submission.csv with exact header annotation_id,concept_name and one prediction for every test annotation_id. Row order may vary; alignment is by exact ID. Names are whitespace-stripped, then matched case-sensitively. Blank cells, misspellings and unknown names are well-formed predictions; unknown names have loss12. Missing, duplicate or extra IDs, extra columns, invalid encoding or malformed CSV are invalid and receive no numerical score. Do not omit difficult regions.

For eligible known names, hierarchical distance sums seven ranks Kingdom,Phylum,Class,Order,Family,Genus,Species:0 for equal values including two nulls,1 for exactly one null,2 for unequal non-null values. If predicted and reference names differ, add1 when the prediction is one of Caridea,Acanthascinae,Actinopterygii,Zoantharia,Tunicata and add1 when the reference is in that set. Mean distance over all test regions is minimized, with no intermediate rounding; equal losses tie. All common taxonomy and exception conventions are fixed. No external synonyms or taxonomy completion are applied.

Use training data to fit models and public validation to make choices. You have30 minutes,2 CPUs and4GiB, and locally installed Python packages including Pillow,numpy,pandas,scipy,scikit-learn and threadpoolctl. See DATA.md for file contents and image attribution.

All 192 frozen target and ancestor names in taxonomy-extended.json are eligible for the identical hierarchical distance. Every other prediction has loss12.
